Can an agent read an accident docket and code the cause as the investigator did?

When the NTSB closes a general-aviation accident investigation, it publishes a probable cause and a set of codes. This agent reads the same public evidence files and codes the case itself. The NTSB's own verdict is the answer key.

Read this first. The agent agrees with the investigator's first code on a minority of cases, and a simpler method does about as well. This site is the record of how that was measured, step by step.

How the agent got there

The agent states what it believes before it reads anything, then after each choice of what to read. Seven documents were in this docket. It read three.

6

The path taken, in eight questions

1Is there an answer key nobody had to write?Yes. The NTSB codes every closed case.
2Is one model call enough?No. It scored below a method that uses no model.
3Does reading the docket help?Yes. This is the largest gain.
4Does reading scanned pages help?Not shown yet, and costly. Paused, and a candidate to return.
5Are the misses about evidence or coding?Mostly the order of the codes.
6How consistent is the answer key itself?Identical cause sentences often carry different first codes.
7Does choosing what to read beat reading everything?Level so far, at a higher cost.
8Does it hold on newly closed cases?The board above is the test.
