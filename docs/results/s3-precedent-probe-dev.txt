## Method

Pool: the S3 statistics pool, development split, classes C/F/L, excluding dev-400, dev-seal-400 and dev-seal-s3-400 (scripts/coding_stats.py, decisions 0094, 129): 12090 cases; kept, each with an NTSB probable-cause text and at least one occurrence code: 12090 (event years 2009-2019); left out: 0 with no probable-cause text, 0 more with no occurrence code. The judged cases' event dates come from the same processed file.
Search: BM25 (k1 = 1.2, b = 0.75; IDF = ln(1 + (N - df + 0.5) / (df + 0.5))) over the lower-cased word tokens ([a-z0-9]+) of the pool's NTSB probable-cause texts, less a fixed list of 134 English stop words. Each distinct query word counts once; a pool case sharing no word with the query is not ranked. The five highest-ranked, ties by case id ascending.
Date-limited pool (the headline): only pool cases whose event date is strictly earlier than the judged case's; N, df and the average length over that set.
Whole pool: every pool case except those on the judged case's event date; statistics over that set.
Queries: the final answer's probable cause and, separately, its evidence narrative. A case counted as failed (decision 0136 item 1) has no query and is not found; it stays in the denominator.
Measures: found@5, the NTSB's first occurrence code (six digits) is the first code of at least one of the five; nearest@1, of the highest-ranked; majority@5, the commonest first code among the five (ties by rank) is it; event-only@5, its event (last three digits) is that of one of the five's first codes.
Control (no search): the NTSB's first code is among the five commonest first codes of the same pool (ties by code ascending); every case counts, failed or not, as it needs no answer. Phase-aware control: the five commonest first codes among the pool cases whose first code has the phase of the loop's own answer's first code; a case with no answer is not found.
The five commonest first codes of the kept pool, for reference: 552230 Landing-Landing Roll / Loss of control on ground (967); 551092 Landing-Flare/Touchdown / Hard landing (425); 300230 Takeoff / Loss of control on ground (365); 402341 Enroute-Cruise / Loss of engine power (total) (325); 550230 Landing / Loss of control on ground (313).
