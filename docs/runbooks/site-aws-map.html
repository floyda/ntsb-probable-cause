Terms

Stack
A group of AWS parts that CDK creates, changes and removes together, from code in infra/.
Origin access control
The rule that only this CloudFront distribution may read the site bucket.
Invalidation
Telling CloudFront to drop its stored copies so readers get the new files.
Content-Security-Policy
A header telling the browser to load scripts, styles and images from the site itself only.
Webhook
GitHub's message to CodeBuild on each push to the branch.
