# S5 step 1 — The skeleton: implementation plan

**Spec:** docs/specs/2026-10-04-s5-public-site-design.md

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Tick a step in the same commit as its code (decision 0017). Log every departure from this plan in the **Deviations** section at the end. Tasks marked **Controller** are run by the controller session, not a subagent: they need Andy.

**Goal:** Step 1 of the specification's order of work (§21): the Astro project in `site/` with pnpm's supply-chain safeguards and strict checks wired into `make check`, the pre-commit hooks and CI; an accessibility check over every built page; and the AWS stacks that serve a holding line at `ellery.demo.floyda.dev`, rebuilt by CodeBuild, ready for Andy to deploy.

**Architecture:** `site/` is a self-contained pnpm project (Astro, strict TypeScript). Three CDK stacks in `infra/`: `NtsbSiteDnsStack` (the `demo.floyda.dev` zone) and `NtsbSiteEdgeStack` (the certificate) in `us-east-1`, where CloudFront needs the certificate, and `NtsbSiteStack` in `eu-west-2` (the private site bucket, CloudFront with origin access control, the CodeBuild project, the event rules, an alert topic). CodeBuild runs `site/scripts/publish.sh` from the repository; in step 1 the only mode is `holding`, which publishes `site/holding/` and nothing else, so no page of the site can reach the public address before Andy decides to launch (§20). Nothing in step 1 reads S4's export; the rule and the read permission for it are created only when the live bucket's name is given as CDK context.

**Tech Stack:** Node 24 (LTS) and pnpm 11 for `site/`: Astro, TypeScript (strictest), ESLint (typescript-eslint, eslint-plugin-astro with its strict accessibility rules), Prettier with its Astro plugin, Playwright with axe-core. Python 3.14 for `infra/` and the tests: aws-cdk-lib (already a dev dependency), pytest, PyYAML (already a dev dependency).

## Global Constraints

- **Branch.** `s5-public-site` in `.claude/worktrees/s5-public-site`. Never commit to `main`.
- **Launch is Andy's decision** (spec §20). Step 1 publishes the holding line only. `publish.sh` refuses every mode but `holding`; a later plan adds the site mode behind a CDK context switch that only Andy's deploy can turn.
- **pnpm safeguards** (spec §17.2), in `site/pnpm-workspace.yaml`: `minimumReleaseAge: 10080`; `trustPolicy: no-downgrade`; `strictDepBuilds: true`; `blockExoticSubdeps: true`; an `allowBuilds` map naming every package allowed a build script (empty unless an install fails on one, which is then reviewed and logged in Deviations). Installs everywhere but the first `pnpm add` use `--frozen-lockfile`. `site/package.json` pins `packageManager` to an exact pnpm version.
- **Versions** are resolved by `pnpm add` at execution time, under the 7-day minimum release age, and recorded in the lockfile; this plan never types a package version. GitHub Actions are pinned by full commit SHA with the version in a comment, as in `ci.yml`.
- **Dependabot** watches `site/` (`npm` ecosystem) weekly with `cooldown: default-days: 7`.
- **Strict checks** (decision 0011): `tsconfig` extends `astro/tsconfigs/strictest`; `astro check` with zero errors and zero warnings; ESLint with type-checked strict rules and zero warnings; Prettier check. All run by `make site-check`, which `make check` calls, by pre-commit on `site/` files, and by CI.
- **Accessibility** (spec §12 item 8, §19.2): an automated WCAG 2.2 AA check (axe-core rule tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`) over every built page and the holding page, in light and dark colour schemes, fails on any violation.
- **No third-party requests at read time** (spec §17.4): no font, script or style from another site.
- **AWS.** Region `eu-west-2` for the site stack, `us-east-1` for the zone and certificate. No account number in any committed file (`infra/app.py` leaves the account unset). Every resource carries a one-line comment with what it is and what it costs, as in `recorder_stack.py`. Context values are passed on the command line, never committed: `site_source_branch`, `alert_email`, `live_bucket_name` (optional).
- **Andy runs every `cdk deploy`** (the stacks create roles), adds the NS records, completes the GitHub connection and confirms the alert email (spec §18.2).
- **Python style:** the test and stack code here is a sketch of content; `ruff format` and `ruff check` (line length 100) have the last word, so split any long literal they flag.
- **Tests offline** (`pytest-socket`); the stack tests skip with a stated reason when `node` is not on `PATH`, like `tests/test_infra_stack.py`. `make check` green at every commit. Clinical tone in every text (rule 6). Commit messages end with the attribution lines the session gives.

## Review Focus

1. **A reader types `/methods` or `/methods/`** (no file name): the address must resolve to `methods/index.html`, not CloudFront's access-denied error. Pinned by Task 5's URL-rewrite test.
2. **A reader follows a broken link**: they must get the site's 404 page with status 404, never S3's XML access-denied page with 403. Pinned by Task 5's error-response test.
3. **A deploy in progress**: a reader must never get a page whose styles are not yet uploaded. Pinned by Task 4's publish-order test.
4. **S4 writes `index.json` or a case file**: only `_finished.json` may start a build, or one night would start dozens. Pinned by Task 5's event-pattern test.
5. **The build role and S4's bucket**: it may read `export/board-1/` and nothing else there (never `runs/`, `scores/` or `nights/`). Pinned by Task 5's IAM test.

```python
Andy asked (2026-10-11) that the site's dependencies be locked and that new releases not be

import re
from pathlib import Path
from typing import Any

import yaml

_SITE = Path(__file__).resolve().parents[1] / "site"
_SEVEN_DAYS_IN_MINUTES = 7 * 24 * 60


def _workspace() -> dict[str, Any]:
    loaded: dict[str, Any] = yaml.safe_load((_SITE / "pnpm-workspace.yaml").read_text())
    return loaded


def test_minimum_release_age_is_at_least_seven_days() -> None:
    assert _workspace()["minimumReleaseAge"] >= _SEVEN_DAYS_IN_MINUTES


def test_trust_policy_refuses_a_downgrade() -> None:
```

`site/tests/a11y.spec.ts`:

```ts
import { existsSync, readdirSync, statSync } from "node:fs";
import { join, relative, sep } from "node:path";
import AxeBuilder from "@axe-core/playwright";
import { expect, test } from "@playwright/test";

// Every built page, by its address: dist/methods/index.html -> /methods/.
function pages(root: string, prefix: string): string[] {
  if (!existsSync(root)) return [];
  const found: string[] = [];
  const walk = (dir: string): void => {
    for (const name of readdirSync(dir)) {
      const path = join(dir, name);
      if (statSync(path).isDirectory()) walk(path);
      else if (name.endsWith(".html")) {
        const rel = relative(root, path).split(sep).join("/");
        found.push(prefix + rel.replace(/(^|\/)index\.html$/, "$1"));
      }
    }
  };
  walk(root);
  return found.sort();
}

const addresses = [...pages("dist", "/"), ...pages("holding", "/_holding/")];

test("there is at least one page to check", () => {
  expect(addresses.length).toBeGreaterThan(0);
});

for (const address of addresses) {
  test(`WCAG 2.2 AA: ${address}`, async ({ page }, info) => {
    await page.goto(address);
    const results = await new AxeBuilder({ page })
      .withTags(["wcag2a", "wcag2aa", "wcag21a", "wcag21aa", "wcag22aa"])
      .analyze();
    expect(results.violations, JSON.stringify(results.violations, null, 2)).toEqual([]);
    if (info.project.name === "phone") {
      const name = address.replace(/[^a-z0-9]+/gi, "-").replace(/^-|-$/g, "") || "home";
      await page.screenshot({ path: `test-results/phone/${name}.png`, fullPage: true });
    }
  });
}
```

```bash
#!/usr/bin/env bash
# Publishes the site to its bucket and clears CloudFront's copies (S5 spec §18.1, §19.1).
# Run by CodeBuild from the repository root. Step 1 has one mode, `holding`, which publishes
# site/holding/ only: launch is Andy's decision (spec §20), and a later plan adds the site
# mode behind a switch only his deploy can turn.
set -euo pipefail

: "${SITE_BUCKET:?SITE_BUCKET is not set}"
: "${DISTRIBUTION_ID:?DISTRIBUTION_ID is not set}"

case "${SITE_MODE:-}" in
  holding) out="site/holding" ;;
  *)
    echo "publish.sh: mode '${SITE_MODE:-}' is not allowed in step 1; only 'holding'" >&2
    exit 2
    ;;
esac

target="s3://${SITE_BUCKET}"
# Styles, scripts and images first, so no page is ever served before the files it names.
aws s3 sync "$out" "$target" --exclude "*.html"
# Then the pages.
aws s3 sync "$out" "$target" --exclude "*" --include "*.html"
# Then remove what is no longer used.
aws s3 sync "$out" "$target" --delete
# Then clear CloudFront's copies: one path, "/*", counts as one invalidation.
aws cloudfront create-invalidation --distribution-id "$DISTRIBUTION_ID" --paths "/*"
```

```js
// Maps a folder address to its index page, so /methods and /methods/ both serve
// methods/index.html (S5 spec §17.4). An address whose last part has a dot is a file and
// passes unchanged. Tested by tests/test_infra_site_stacks.py.
function handler(event) {
  var request = event.request;
  var uri = request.uri;
  if (uri.endsWith("/")) {
    request.uri = uri + "index.html";
  } else if (uri.split("/").pop().indexOf(".") === -1) {

  }
```

```python
def _holding_style_hash() -> str:
    """The CSP hash of the holding page's one inline style block (spec §17.4: no 'unsafe-inline')."""
    page = (_REPO_ROOT / "site/holding/index.html").read_text()
    match = re.search(r"<style>(.*?)</style>", page, re.DOTALL)

        self.certificate = acm.Certificate(
            self,
            "Certificate",
            domain_name=SITE_DOMAIN,
            validation=acm.CertificateValidation.from_dns(zone),
        )


class NtsbSiteStack(Stack):
    """The site bucket, CloudFront, the build and its rules."""

    def __init__(
        self,
        scope: Construct,
        construct_id: str,
        *,
        env: Environment,
        zone: route53.IHostedZone,
        certificate: acm.ICertificate,
        source_branch: str,
        alert_email: str,
        live_bucket_name: str | None,
    ) -> None:
        super().__init__(scope, construct_id, env=env, cross_region_references=True)

        # The site's files: private, versioned. A few megabytes, inside the flat-rate plan's
        # 5 GB S3 credit: about $0.
        bucket = s3.Bucket(
            self,
            "SiteBucket",
            block_public_access=s3.BlockPublicAccess.BLOCK_ALL,
            encryption=s3.BucketEncryption.S3_MANAGED,
            enforce_ssl=True,
            versioned=True,
            lifecycle_rules=[s3.LifecycleRule(noncurrent_version_expiration=Duration.days(30))],
            removal_policy=RemovalPolicy.RETAIN,
        )

        # Folder addresses to index pages, at the edge: included in the flat-rate plan.
        rewrite = cloudfront.Function(
            self,
            "UrlRewrite",
            code=cloudfront.FunctionCode.from_file(
                file_path=str(Path(__file__).with_name("site_url_rewrite.js"))
            ),
            runtime=cloudfront.FunctionRuntime.JS_2_0,
        )

        # Security headers and a Content-Security-Policy that allows the site's own files only.
        headers = cloudfront.ResponseHeadersPolicy(
            self,
            "Headers",
            security_headers_behavior=cloudfront.ResponseSecurityHeadersBehavior(
                content_security_policy=cloudfront.ResponseHeadersContentSecurityPolicy(
                    content_security_policy=(
                        "default-src 'self'; img-src 'self' data:; "
                        f"style-src 'self' {_holding_style_hash()}; "
                        "base-uri 'none'; form-action 'none'; frame-ancestors 'none'"
                    ),
                    override=True,
                ),
                content_type_options=cloudfront.ResponseHeadersContentTypeOptions(override=True),
                frame_options=cloudfront.ResponseHeadersFrameOptions(
                    frame_option=cloudfront.HeadersFrameOption.DENY, override=True
                ),
                referrer_policy=cloudfront.ResponseHeadersReferrerPolicy(
                    referrer_policy=cloudfront.HeadersReferrerPolicy.STRICT_ORIGIN_WHEN_CROSS_ORIGIN,
                    override=True,
                ),
                strict_transport_security=cloudfront.ResponseHeadersStrictTransportSecurity(
                    access_control_max_age=Duration.days(365),
                    include_subdomains=False,
                    override=True,
                ),
            ),
        )

        # The distribution: $0 on the flat-rate Free plan (spec §18.3), chosen per Task 5
        # Step 1's finding (in code if CDK can, otherwise once in the console, runbook).
        distribution = cloudfront.Distribution(
            self,
            "Distribution",
            default_behavior=cloudfront.BehaviorOptions(
                origin=origins.S3BucketOrigin.with_origin_access_control(bucket),
                viewer_protocol_policy=cloudfront.ViewerProtocolPolicy.REDIRECT_TO_HTTPS,
                function_associations=[
                    cloudfront.FunctionAssociation(
                        function=rewrite, event_type=cloudfront.FunctionEventType.VIEWER_REQUEST
                    )
                ],
                response_headers_policy=headers,
            ),
            domain_names=[SITE_DOMAIN],
            certificate=certificate,
            default_root_object="index.html",
            error_responses=[
                cloudfront.ErrorResponse(
                    http_status=403, response_http_status=404, response_page_path="/404.html"
                ),
                cloudfront.ErrorResponse(
                    http_status=404, response_http_status=404, response_page_path="/404.html"
                ),
            ],
            minimum_protocol_version=cloudfront.SecurityPolicyProtocol.TLS_V1_2_2021,
        )

        # The site's name, pointing at the distribution: alias lookups are free.
        record_name = SITE_DOMAIN.removesuffix(f".{ZONE_NAME}")
        alias = route53.RecordTarget.from_alias(route53_targets.CloudFrontTarget(distribution))
        route53.ARecord(self, "AliasA", zone=zone, record_name=record_name, target=alias)
        route53.AaaaRecord(self, "AliasAAAA", zone=zone, record_name=record_name, target=alias)

        # Alerts: an email when a build fails. SNS email: free at this volume.
        topic = sns.Topic(self, "AlertTopic")
        topic.add_subscription(subscriptions.EmailSubscription(alert_email))

        # The build: smallest machine, 15-minute limit. 100 free minutes a month; about
        # 60 to 90 used (estimate, spec §18.3): about $0.
        project = codebuild.Project(
            self,
            "Build",
            source=codebuild.Source.git_hub(
                owner=_GITHUB_OWNER,
                repo=_GITHUB_REPO,
                branch_or_ref=source_branch,
                webhook=True,
                webhook_filters=[
                    codebuild.FilterGroup.in_event_of(codebuild.EventAction.PUSH).and_branch_is(
                        source_branch
                    )
                ],
            ),
            environment=codebuild.BuildEnvironment(
                build_image=codebuild.LinuxBuildImage.STANDARD_7_0,
                compute_type=codebuild.ComputeType.SMALL,
                environment_variables={
                    "SITE_MODE": codebuild.BuildEnvironmentVariable(value="holding"),
                    "SITE_BUCKET": codebuild.BuildEnvironmentVariable(value=bucket.bucket_name),
                    "DISTRIBUTION_ID": codebuild.BuildEnvironmentVariable(
                        value=distribution.distribution_id
                    ),
                },
            ),
            timeout=Duration.minutes(15),
            build_spec=codebuild.BuildSpec.from_object(
                {
                    "version": "0.2",
                    "phases": {"build": {"commands": ["bash site/scripts/publish.sh"]}},
                }
            ),
        )
        bucket.grant_read_write(project)
        bucket.grant_delete(project)
        project.add_to_role_policy(
            iam.PolicyStatement(
                actions=["cloudfront:CreateInvalidation"],
                resources=[
                    f"arn:aws:cloudfront::{self.account}:distribution/{distribution.distribution_id}"
                ],
            )
        )
        project.on_build_failed("BuildFailed", target=targets.SnsTopic(topic))

        if live_bucket_name is not None:
            # S4's export: read the export folder only (spec §22). Not runs/, scores/, nights/.
            project.add_to_role_policy(
                iam.PolicyStatement(
                    actions=["s3:GetObject"],
                    resources=[f"arn:aws:s3:::{live_bucket_name}/{EXPORT_PREFIX}*"],
                )
            )
            project.add_to_role_policy(
                iam.PolicyStatement(
                    actions=["s3:ListBucket"],
                    resources=[f"arn:aws:s3:::{live_bucket_name}"],
                    conditions={"StringLike": {"s3:prefix": [f"{EXPORT_PREFIX}*"]}},
                )
            )
            # S4's finished mark starts a build; nothing else in its bucket does. Free.
            events.Rule(
                self,
                "ExportFinished",
                event_pattern=events.EventPattern(
                    source=["aws.s3"],
                    detail_type=["Object Created"],
                    detail={
                        "bucket": {"name": [live_bucket_name]},
                        "object": {"key": [FINISHED_KEY]},
                    },
                ),
                targets=[targets.CodeBuildProject(project)],
            )

        CfnOutput(self, "SiteBucketName", value=bucket.bucket_name)
        CfnOutput(self, "DistributionId", value=distribution.distribution_id)
        CfnOutput(self, "DistributionDomainName", value=distribution.distribution_domain_name)
        CfnOutput(self, "BuildProjectName", value=project.project_name)
        CfnOutput(self, "AlertTopicArn", value=topic.topic_arn)
```
