# S2.5 — The recorder: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** docs/specs/2026-09-22-s25-recorder-design.md

**Goal:** A nightly job that polls every ongoing Part 91 investigation, records when each
docket document and each structured evidence field first appears, and stores the
preliminary narrative — in a SQLite store, on AWS, with Andy's Mac as a bridge.

**Architecture:** Three new packages over the existing library: `store/` (the only code that
touches SQLite), `recorder/` (the nightly logic, every network and clock call injected),
`apps/recorder/` (the `ntsb-record run` entrypoint). The S2 docket client fetches listings
with its cache off; the existing API client fetches event months and gains one method for the
change feed. Every "when" is an interval between two run ids. Specification:
`docs/specs/2026-09-22-s25-recorder-design.md` (Approved 2026-09-22); decisions 0060–0071.

**Tech Stack:** Python 3.14, `sqlite3` (standard library), pydantic, httpx + respx (tests),
`boto3` behind an `aws` extra for the S3 sync, AWS CDK (Python) under `infra/`, Docker.

## Global Constraints

Every task's requirements include these. Copied from the specification and CLAUDE.md.

- `make check` (ruff format, ruff check, import-linter, deptry, vulture, `mypy --strict`,
  pytest with `--disable-socket` and `--cov-fail-under=90`) must pass after every task.
- The docket client's rate floor is one request every 2.0 seconds to `data.ntsb.gov`; the API
  client's is 30 requests a minute. Tests inject `sleep`, never set the rate to 0.
- No document is ever downloaded (0061). The recorder calls `DocketClient(cache_dir=None)` (0066).
- Every record passes through `split_record`; only `Evidence` is ever written (0064 rule 3).
  No synthesis or verdict string may appear in the SQLite file, checked as bytes.
- Every "when" is a pair of run ids: last seen absent, first seen present (spec §3). Never a
  single guessed date. All timestamps UTC ISO-8601.
- Watched = `mode` aviation, `completionStatus == "Ongoing"`, regulation `"091"` or empty, or
  within 30 days of leaving `Ongoing` (0067, 0064). Never `!= "Completed"`.
- Open-split text (titles, narratives, pages) lives only in the store. Scripts print counts
  only: no case numbers, no titles, no text (0024).
- Every script in `scripts/` opens with a `Status` docstring block (0059): kind, what it
  produced, what has since changed.
- Nothing under `data/` is committed. The store's default path is `data/recorder.sqlite`.
- Logs never contain case text. One line per case per side, one per step, the summary last.
- Plans live in `docs/plans/`; tick tasks in the same commit as their code; log deviations in
  the "Deviations" section at the end of this file.
- Commit messages: `S2.5: <what>`; end with the attribution lines the session reminder gives.
- Simplified technical English in the runbook, with a glossary; clinical tone everywhere.

```python
_INFO_BLOCK = re.compile(r"<h2><b>Docket Information</b></h2>")
_CREATION = re.compile(r"<b>Creation Date:</b>\s*([^<]*)<")
_MODIFIED = re.compile(r"<b>Last Modified:</b>\s*([^<]*)<")
_RELEASE = re.compile(r"Public Release Date &(?:amp;)? Time:\s*([^<]*)<")


class DocketInfo(BaseModel):
    """The docket-level dates the page prints, as printed. Not per document (spec §6.2)."""

    model_config = ConfigDict(frozen=True)
    creation_date: str | None
    last_modified: str | None
    release_date: str | None


def _info(page: str) -> DocketInfo | None:
    if not _INFO_BLOCK.search(page):
        return None

    def first(pattern: re.Pattern[str]) -> str | None:
        match = pattern.search(page)
        value = html.unescape(match.group(1)).strip() if match else ""
        return value or None

    return DocketInfo(
        creation_date=first(_CREATION), last_modified=first(_MODIFIED), release_date=first(_RELEASE)
    )
```
